# Changelog

All notable changes to Nova AI Media Player are documented here.

## [1.0.0] — Version 01

### Added

- Modern PySide6 Windows media-player interface
- Audio/video playback and playlist queue
- Library and favorites workflows
- Continue Watching and saved playback positions
- Multiple interface themes/layouts and Theme Center
- Mini Player and Cinema Mode
- Universal Search and Command Palette
- Subtitle Center, subtitle editor, transcript viewer and translation tools
- Local faster-whisper transcription with CPU/CUDA-aware selection
- Nova Intelligence workspace and AI command tools
- Screenshots, bookmarks, equalizer, audio output and video adjustments
- FFmpeg conversion/export and media information
- Task/activity logging and diagnostics
- Session/crash recovery and single-instance behavior
- Nova application icon and About developer credit
