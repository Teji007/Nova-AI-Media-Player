# Code of Conduct

## Our standard

Participants are expected to be respectful, constructive, and professional. Harassment, discrimination, threats, personal attacks, and deliberate disruption are not acceptable.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation when behavior violates these standards.

To report a conduct concern, use a private communication channel available through the repository maintainer's GitHub profile rather than posting sensitive details publicly.
