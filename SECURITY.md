# Security Policy

## Supported version

The current public version is **01 (1.0.0)**.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue.

Use GitHub's private security reporting / security advisory mechanism for the repository when available, or contact the maintainer privately through GitHub.

Include the affected version, reproduction steps, impact, and any relevant logs that do not contain secrets.

## Secrets

Never commit `NOVA_OPENAI_API_KEY`, API tokens, passwords, or private configuration files. Use environment variables or local settings instead.
